# 워드 편집기 모듈 (`src/lib/word`)

A4 종이 모양 화면에서 문서를 쓰고 .docx 로 저장·불러오는 모듈입니다. 쓰일 곳(전자결재 본문·공문·회의록 등)이 정해지면 붙입니다.
확인용 화면: `/word-editor`(편집기만 있는 새 탭 — 새 문서·.docx 열기·저장·인쇄, 쓰던 문서는 브라우저에 남음).

## 경계 규칙

- 이 폴더 안 파일은 **같은 폴더 파일(`./…`)·`react`·`@tiptap/*`만** 불러옵니다(`docx.test.ts`가 검사). 폴더째 다른 프로젝트로 옮길 수 있습니다.
- 바깥에서는 `index.ts`(`@/lib/word`, 편집기 포함) 또는 `core.ts`(`@/lib/word/core`, 저장·불러오기만)로 불러옵니다.
- zip·xml 읽기는 시트 모듈과 같은 코드를 이 폴더에 따로 둡니다(모듈끼리 서로 기대지 않게).

## 데이터

편집기(Tiptap)의 문서 JSON 그대로(`WordNode`). 노드·글 표시 목록은 `model.ts` 맨 위 설명.

## .docx 저장·불러오기 (외부 라이브러리 없이)

| | 저장 `exportDocx` | 불러오기 `importDocx` |
|---|---|---|
| 문단·제목(1~6)·정렬 | ○ | ○ (스타일 이름 heading/제목, 개요 수준) |
| 굵게·기울임·밑줄·취소선·크기·색·글꼴·형광펜 | ○ | ○ |
| 링크·줄바꿈·탭 | ○ | ○ |
| 글머리·번호 목록(여러 단계) | ○ | ○ |
| 인용·구분선 | ○ | 인용은 본문 문단으로 |
| 표(가로·세로 합친 칸, 머리 칸, 열 너비) | ○ | ○ |
| 그림(PNG·JPEG·GIF) | ○ | ○ |
| 머리글·바닥글·각주·메모·변경 추적·도형 | — | 읽지 않음(안내 문구) |

쪽은 A4 세로, 여백 2.54cm, 글꼴 맑은 고딕 10pt(편집 화면과 같음).
