# 대체휴무 자동 지급(분 단위)·반차 4시간 규칙 — 설계

2026-11-13 · 브랜치 `feature/workplan-merge-main` · 화면은 사용자가 줄 화면설계서로 나중에. 이번은 내부 계산과 그 계산을 쓰는 곳 맞추기.

## 1. 사용자가 정한 것

1. **대체휴무 자동 지급** — 휴일근로 신청서가 **결재 완료**된 건만, 휴일근로 시간(분) × 1.5 를 대체휴무로 지급한다.
   예: 8시간 30분 = 510분 → 대체휴무 765분.
   - 휴일근로 시간 = 결재 완료 문서의 출근~퇴근 시각(신청서는 근태 기록으로 자동 입력되고 기안자가 못 고침)으로 계산.
2. **단위** — 연차는 개수(1·0.5·0.25), 대체휴무는 시간(분)으로 쌓는다. 근로시간은 항상 분 단위.
3. **대체휴무 사용** — 휴가원에서 연차처럼 **종일 1개(480분)·반차 0.5개(240분)·반반차 0.25개(120분)** 단위로 쓴다.
4. **반차·반반차** — 하루 기본 근무 8시간. 반차 4시간, 반반차 2시간. 오전반차는 13:30 출근, 오후반차는 12:30 퇴근. 반차는 점심시간 없이 근무시간만 4시간 채우는 것.
5. **기존 수동 대체휴무**(관리자가 일 단위로 준 것) — 사용된 적이 있는지 확인하고, 없으면 모두 폐기.
6. 화면(UI)은 화면설계서가 오면 따로. 이번엔 내부 계산을 바꾸고 그 계산을 쓰는 곳(잔여 표시·근태 판정·홈 위젯·모바일)을 새 값에 맞춘다.

## 2. 계산 규칙

### 2.1 휴일근로 → 대체휴무 지급(분)

- 대상 문서: 서식 코드 `휴일근무`(예전 `연장근로`), 상태 `완료`, 근무 구분이 **휴일**인 문서.
- 근로 분 = 출근~퇴근(자정 넘으면 +24시간) − 휴게시간과 겹친 분. 이미 있는 `overtimeHours` 의 '휴일' 계산과 같은 규칙을 **반올림 없이 분으로** 낸 값.
- 지급 분 = `Math.floor(근로 분 × 1.5)` (765.0 처럼 대부분 정수, .5 가 나오면 버림).
- 시각이 없거나 0분이면 지급 없음.
- **대체휴무 원장(`substituteHolidayLedger`, 새 컬렉션)에 저장한다**(사용자 결정 11-13). 결재 문서는 읽기만 한다.
  - 한 줄 = 한 건: `id, userId, kind(GRANT|REVOKE), minutes(지급 +, 차감 −), sourceDocId, sourceDocNo, workDate, expiresOn, workMinutes, createdAt, createdBy, note`.
  - **지급**: 휴일근로 문서가 최종 결재 완료될 때 `GRANT` 한 줄(`id = SHL-G-{문서id}`).
  - **자동 차감**: 그 문서의 취소 기안이 최종 승인되어 원문서가 `취소완료`가 될 때 `REVOKE` 한 줄(`id = SHL-R-{원문서id}`, 지급과 같은 분을 −로). 지우지 않는다.
  - id 가 근거 문서로 정해져 같은 문서로 두 번 들어가지 않는다(이미 있으면 건너뜀).
  - **빠진 것 메우기(대조)**: 결재 완료 순간 기록이 실패할 수 있으므로, 결재 완료·취소완료 휴일근로 문서와 원장을 대조해 빠진 줄만 넣는 함수와 스크립트(`scripts/reconcile-substitute-ledger.ts`, `--dry-run`·`--prod`)를 둔다. 첫 운영 반영 때 이것으로 예전 결재 완료 문서도 넣는다.
- 유효기간: 근무 일자 + 1년(지금 수동 부여와 같은 규칙).

### 2.2 대체휴무 사용(분)

- 휴가 종류 `대체휴무` 문서의 사용 분 = 사용 개수 × 480. 개수는 종일 1 · 반차 0.5 · 반반차 0.25(여러 날이면 날마다 합).
- 잔여 = 유효한 지급 분 합 − 사용 분(완료) − 사용 분(진행 중, 가용 잔여 계산에만). 오래된 지급부터 먼저 쓴다(선입선출, 지금과 같음).
- 표시: `N시간 M분`(예: 765분 → 12시간 45분). 잔여 판단은 분으로.

### 2.3 연차

- 지금처럼 개수(일). 반차 0.5, 반반차 0.25. 바뀌는 것 없음(표기만 '개'로 쓸 수 있게 단위 함수 제공).

### 2.4 반차·반반차 시간대(근태 판정)

- 하루 근무를 점심 제외 480분 타임라인으로 본다(지금 `workSegments`/`netWindows`).
- 오전반차 = 타임라인 0~240분 부재, 오후반차 = 240~480분 부재. 반반차 = 2시간 슬롯(지금 그대로).
- 지금 임시 규칙(반차 경계 = 점심시간)은 점심 위치에 따라 3시간/5시간이 될 수 있었다 → **항상 근무시간 4시간**으로 바꾼다. 점심 12:30~13:30 이면 오전반차 13:30 출근·오후반차 12:30 퇴근(사용자 예시와 같음).
- 대체휴무 반차·반반차도 같은 시간대 규칙을 쓴다(종류가 대체휴무여도 반차면 반차 시간대).

## 3. 휴가원에 필요한 값(화면설계서 전 내부 약속)

- 휴가 문서가 '반차/반반차'인지 알 수 있어야 한다. 연차는 지금 휴가 종류(`오전반차`·`오후반차`·`반반차`)로 알 수 있다.
- 대체휴무는 종류가 하나(`대체휴무`)라 단위를 따로 받아야 한다 → 문서 값 `leaveUnit`: `종일`·`오전반차`·`오후반차`·`반반차`(없으면 종일). 반반차 시간대는 지금처럼 `quarterSlot`.
- 계산은 `leaveUnit` 을 읽도록 먼저 만들고, 화면설계서가 오면 휴가원 화면에서 이 값을 채운다. **서식 마스터(approvalForms)는 이번에 바꾸지 않는다**(읽기 전용 규칙 — 서식 변경은 화면 작업 때 새 서식/사용자 지시로).

## 4. 기존 수동 대체휴무 폐기

- 운영 `substituteHolidayGrants`(관리자 수동 부여)와 대체휴무 사용 휴가 문서를 대조해 **사용된 적 있는지 보고**한다(읽기만, 스크립트 `scripts/report-manual-substitute.ts`).
- 계산은 수동 부여를 더 이상 읽지 않는다(코드). 관리자 일괄 부여 화면 단추는 숨긴다.
- 운영 데이터 삭제는 사용자 지시 후, 지우기 전 내보내기(백업) 파일을 남긴다. 사용 이력이 있으면 멈추고 보고.

## 5. 바뀌는 곳

- `src/domain/leave/substituteLedger.ts`(새): 원장 줄 스키마, 휴일근로 분·지급 분 계산, 지급·차감 줄 만들기, 대조(빠진 줄), 사용 분, 선입선출 잔여, `N시간 M분` 표시.
- `src/data/substituteLedger/*`(새): 원장 저장소(전 직원 공용 목록), 결재 완료·취소완료 때 기록(`approvalDoc.repo` 완료 처리 뒤, 실패해도 결재는 그대로).
- `src/domain/leave/userLeaveBalance.ts`: `substituteHoliday` 를 분 단위로(`totalMin/usedMin/pendingMin/remainingMin`, detailList 는 원장 지급 줄별). 수동 부여 읽기 제거.
- `src/domain/commute/engine.ts`: 반차 시간대 = 근무 240분, 대체휴무의 `leaveUnit` 반영.
- 대체휴무 잔여·이력을 보여 주는 곳(홈 위젯, 모바일 휴가 원장, 근태 화면, 휴가 신청 시 잔여 검사)을 분 값·`N시간 M분` 표시로 맞춤. 관리자 수동 부여 화면은 쓰지 않게 숨김.

## 6. 만드는 사람에게 맡긴 것 / Claude 가 정한 것(확인 필요)

- 근무 구분이 **연장**(평일 퇴근 후)인 문서는 지급하지 않는다 — 휴일근로만.
- 1.5배 결과의 소수는 버림.
- 원장 id 를 근거 문서로 정해 이중 지급 없음, 대조 함수로 빠진 줄 보충.
- 유효기간 근무일 + 1년.
- 반차 경계를 '근무 4시간'으로(점심 위치와 무관).
- 대체휴무 단위 값 `leaveUnit` 은 화면설계서 전 내부 약속 — 화면 작업 때 이 이름으로 채운다.

검증: 단위 테스트(510분→765분, 휴게 겹침, 자정 넘김, 반려 문서 제외, 선입선출, 반차 시간대), `npx tsc --noEmit`, 전체 테스트, 빌드. 운영 반영(배포·수동 부여 폐기)은 사용자 지시 후.
