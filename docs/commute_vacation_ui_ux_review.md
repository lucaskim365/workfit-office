# WorkFit 근태·휴가 관리 모듈 UI/UX 및 IA 고도화 가이드

## 1. 개요 및 핵심 방향성
본 문서는 WorkFit 그룹웨어의 **근태·휴가 관리** 모듈에 대해, PM·실무 사용자 및 **조직 관리자(팀장/부서장)**의 관점에서 도출된 구조적 진단과 피드백을 반영하여 실질적이고 즉시 적용 가능한 형태로 고도화한 설계 지침서입니다.

> **핵심 설계 원칙 (Core Principles)**
> 1. **기존 권한 시스템(`scopeHelper.ts`)과의 100% 정합성 준수 및 버그 해소**
>    - 기존에 구현되어 있던 `resolveCommuteScope`(`ALL`, `TEAM`, `MY_ONLY`)를 왜곡 없이 그대로 계승하여 중복 권한 생성 방지.
>    - 팀장(`TEAM`)이 존재함에도 UI에서 관리 탭이 누락되던 기존 화면(`CommuteScreen`) 버그 정상화.
> 2. **"내 것(My)" vs "관리(Management)" 단순 명료한 최상위 구조**
>    - `[내 근태]`와 `[내 연차·휴가]`를 단일 페이지인 **`[내 근태·휴가]`**로 통합하여 사용자 멘탈 모델 일치.
> 3. **역할 기반의 3대 페르소나(팀원 / 팀장 / 인사·임원) 명확화 및 데이터 접근 스코프 분리**
>    - 팀장에게는 타 부서 데이터/민감한 전사 연차 원장을 숨기고 **"우리 팀 출결 현황 & 휴가 공백 관리"**에 집중.
> 4. **"데이터 종류"가 아닌 "관리자의 실제 업무(Action)" 중심의 하위 탭 구조 개편**
>    - 근태 확인 업무(`근태 현황`)와 휴가/원장 관리 업무(`연차·휴가 관리`)로 압축.
> 5. **출퇴근과 휴가가 유기적으로 결합된 스마트 캘린더**
>    - 달력 하나에 출퇴근 시각과 휴가(연차/반차 등) 내역이 함께 표시되어 한 달 근무 흐름을 원스톱 파악.
> 6. **전자결재(Approval) 시스템과의 명확한 책임 분리**
>    - 승인 행위는 전자결재가 전담하고, 누적/조회/원장 관리는 근태·휴가 모듈이 담당.

## 2. 기존 권한 시스템(`scopeHelper.ts`)과의 정합성 및 버그 분석

### 2.1 기존 권한 헬퍼 표준 규칙 (`src/features/auth/scopeHelper.ts`)
우리 시스템은 이미 `resolveCommuteScope(user, userRoles, org)`를 통해 3단계 데이터 스코프(`DataScope`)를 정의하고 있습니다:

```typescript
export type DataScope = 'MY_ONLY' | 'TEAM' | 'TEAM_AND_LEADERS' | 'ALL';

// [규칙]
// 1. 임원 (roleGroups의 OPERATOR/EXEC 또는 임원 직급/직책): 전사 스코프 (ALL)
// 2. 팀장급 (조직도 부서장 또는 팀장/부서장 직책): 본인 부서/팀 스코프 (TEAM)
// 3. 사원 및 일반 관리자(ADMIN): 본인 근태만 (MY_ONLY)
// ⚠️ ADMIN은 시스템 관리 권한일 뿐, 근태 조회는 자신의 본래 인사 스코프를 따릅니다.
```

### 2.2 현행 `CommuteScreen.tsx`의 기존 버그 및 혼선 원인
1. **팀장(`TEAM`)의 관리 권한 누락 (버그)**:
   - 코드상 `const canAll = isAdmin || commuteScope === 'ALL';` 만 검사하여 관리 탭(`TEAM_TAB`)을 노출하고 있었습니다.
   - 이로 인해 `commuteScope === 'TEAM'`(팀장/부서장)으로 판별된 사용자도 UI에서는 관리 탭 버튼이 아예 나타나지 않아 **일반 사원과 동일하게 취급**되고 있었습니다.
2. **탭 명칭의 불일치**:
   - 내부 상수명은 `TEAM_TAB = 'team'`인데, 버튼 라벨은 무조건 `'전사 관리'`로 하드코딩되어 있어 팀장에게 노출시키더라도 업무 영역의 인지적 혼선이 발생했습니다.
3. **민감 정보 격리 부족**:
   - `leave_ledger`(전사 연차 원장 대장)는 인사/임원 전용 민감 데이터이나, 팀장 권한 오픈 시 안전하게 숨길 수 있는 탭 분기 구조가 미흡했습니다.

## 3. 역할 기반 권한 설계 및 스코프 매트릭스 (Role-Based Scope Matrix)

기존 `resolveCommuteScope`의 3대 스코프를 100% 활용하여 화면과 데이터 접근을 동적 분기합니다.

| 사용자 역할 | 기존 `resolveCommuteScope` 결과 | 상단 메뉴 노출 형태 | 접근 가능 탭 & 데이터 조회 범위 | 핵심 관리 목적 |
| :--- | :--- | :--- | :--- | :--- |
| **일반 팀원** | **`MY_ONLY`** | `[내 근태·휴가]` (단일 탭) | - 본인 근태 캘린더<br>- 본인 연차 잔여 및 사용 이력 | 본인 출퇴근 확인, 연차 잔여 조회 및 휴가 신청 |
| **중간 관리자<br>(팀장/부서장)** | **`TEAM`** | `[내 근태·휴가]`<br>+ **`[부서 관리]`** | - **부서 근태 현황** (소속 부서원 일별 매트릭스, 오늘 출결)<br>- **부서 휴가 캘린더** (소속 부서원 휴가 일정/공백 뷰)<br>- *(※ 타 부서 및 전사 연차 원장 조회/수정 원천 차단)* | **오늘 팀원 출결 체크**, **팀 내 휴가 겹침/공백 방지**, 소명/신청 승인 |
| **전사 관리자<br>(인사/임원)** | **`ALL`** | `[내 근태·휴가]`<br>+ **`[전사 관리]`** | - **전사 근태 현황** (전사/부서별 매트릭스, 이상근태 필터)<br>- **연차·휴가 관리** (전사 연차 원장 대장, 입사일/회계연도 토글, 수동 가감) | 법정 연차 정산, 근로기준법 준수 점검, 전사 근태 마감 |

## 4. 사용자 동선 기반 IA (정보 구조) 재설계

```text
근태·휴가 (Commute & Leave)
│
├── 👤 [1] 내 근태·휴가 (전 임직원 공통 마이 대시보드)
│   ├── [상단 요약 바]
│   │   ├── ⏰ 오늘의 근태 (출근/퇴근 시각, 근무 진행 바, 실시간 근무시간)
│   │   ├── 🏖️ 내 연차 잔여 (잔여/총 부여, 대체휴무 잔여)
│   │   ├── 📅 예정된 일정 / 총 근무시간 요약 (이번 주 휴가, 이번 달 누적 근무시간)
│   │   └── ⚡ [+ 휴가 신청] 메인 퀵 액션 (전자결재 기안 연결)
│   ├── [중단 메인: 스마트 캘린더] 출결 타임스탬프(08:55~18:05) + 승인 휴가(연차/반차/대휴) 융합
│   └── [하단 상세 내역] 연차·휴가 증감 내역 (전자결재 문서 링크) 및 출퇴근 소명 신청 이력
│
├── 👥 [2-A] 부서 관리 (commuteScope === 'TEAM' : 팀장/부서장 권한 전용)
│   ├── 1. 부서 근태 현황
│   │   ├── 상단 위젯: "우리 팀 오늘 현황: 총 7명 중 정상 출근 5명 / 휴가 1명 / 미출근 1명(홍길동)"
│   │   ├── 상태 필터: [전체] [정상] [⚠️ 확인 필요 (지각/결근/미기록)]
│   │   └── 부서원 일별 근태 Matrix (소속 부서 고정, 좌측 팀원명 Sticky 고정)
│   └── 2. 부서 휴가 캘린더 (Team Absence Board)
│       ├── 월간/주간 팀원 휴가 타임라인 (누가 언제 자리를 비우는지 한눈에 파악하여 업무 공백 방지)
│       └── 부서원 승인 대기 결재 바로가기
│
└── 🏢 [2-B] 전사 관리 (commuteScope === 'ALL' : 인사담당자 / 임원 권한 전용)
    ├── 1. 전사 근태 현황
    │   ├── 상단 KPI: 전체 인원 | 정상 출근 | ⚠️ 확인 필요 (지각·결근·미기록 통합)
    │   ├── 부서 드롭다운 필터 (전체 부서 조회 가능)
    │   └── 전사 일별 근태 Matrix (부서별 그룹핑 + Sticky 고정)
    └── 2. 연차·휴가 관리 (휴가 정산 및 원장 대장)
        ├── 상단 KPI: 관리 인원 | 총 부여일수 | 총 소진일수 | 평균 소진율 (출퇴근 KPI 완전 분리)
        ├── 뷰 전환: [직원별 연차 대장] | [전사 휴가 현황]
        ├── 기준 토글: 입사일 기준(법정 원칙) / 회계연도 기준(1/1 정산)
        └── 수동 조정: 사원별 가감 이력 조회 및 조정 모달
```

## 5. 팀장(중간 관리자) 전용 뷰 상세 설계

팀장은 전사 통계보다는 **"우리 팀의 오늘 근무 상태"**와 **"업무 공백(휴가 겹침)"** 관리가 최우선입니다.

### 5.1 부서 오늘 근태 요약 위젯
```text
┌─────────────────────────────────────────────────────────────────────────────┐
│ 👥 AX 솔루션컨설팅팀 오늘 근태 현황 (기준: 09:30)                           │
│  - 팀원 총 6명 : 정상 출근 4명 | 🏖️ 휴가 1명 (김대리: 연차) | ⚠️ 지각/미출근 1명 (이주임)   │
│  [이주임에게 확인 알림 전송] [근태 미입력 소명 요청]                         │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 5.2 부서 휴가 공백 캘린더 (Team Absence Timeline)
- **목적**: 동시 휴가로 인한 프로젝트/업무 마비 방지.
- **표현 방식**: 간트차트 또는 월간 캘린더 바 형태.
  - 예: `7월 24일(금): [김대리 - 하계휴가] [박과장 - 하계휴가] ⚠️ 2명 동시 부재 경고 표시`
  - 팀장은 이를 보고 결재 승인 여부나 일정 조율을 선제적으로 판단 가능.

## 7. 관리자 화면 세부 개선 사항 (전사 & 부서 공통)

1. **`이상 근태` 탭 제거 및 필터 흡수**:
   - 상위 탭에서 불필요하게 자리를 차지하던 `이상 근태`를 제거하고, 매트릭스 필터의 `⚠️ 확인 필요 (지각/결근/미기록)`로 1클릭 통합.
   - 단어 톤앤매너 변경: 공포감을 주는 `🚨 관리 필요(빨간색)` ➔ 실무적이고 객관적인 `⚠️ 확인 필요`.
2. **Matrix 뷰 Sticky 고정 (필수 개선 UX)**:
   - 가로 스크롤 시 좌측 `[부서 / 직원명]` 컬럼을 `position: sticky; left: 0; z-index: 10;`으로 고정하여 31일까지 넘겨도 사원 식별성 보장.
3. **연차 관리 화면 2중 출퇴근 KPI 완전 제거**:
   - 연차 대장을 볼 때 상단에 자리 잡고 있던 일별 출결 KPI(출근 0, 결근 265)를 완전히 걷어내고 연차 지표만 단독 노출.
4. **인터랙티브 범례**:
   - `정상 / 지각 / 결근 / 휴가 / 미기록` 범례를 클릭하면 해당 상태를 가진 셀/직원만 즉시 하이라이트.
