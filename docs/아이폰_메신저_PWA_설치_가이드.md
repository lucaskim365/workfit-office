# 📱 워크핏 메신저 — 아이폰 설치 & 알림 설정 가이드

> 아이폰에서 **앱스토어 설치 없이** 워크핏 메신저를 앱처럼 사용하고, 새 메시지 **푸시 알림**을 받는 방법입니다.

---

## ✅ 준비 사항 (꼭 확인)

| 항목 | 조건 |
| :--- | :--- |
| **아이폰 iOS 버전** | **iOS 16.4 이상** (설정 → 일반 → 정보에서 확인, 낮으면 먼저 업데이트) |
| **브라우저** | 반드시 **Safari** (크롬·기타 브라우저는 설치·알림 불가) |
| **접속 주소** | **https://intra.widdyax.com/m** |

> ⚠️ **중요**: iPhone 웹 푸시는 **"홈 화면에 추가"로 설치한 앱**에서만 작동합니다. Safari로 그냥 보는 상태에서는 알림이 오지 않습니다.

---

## 1단계. 홈 화면에 앱 설치하기

1. 아이폰에서 **Safari**를 엽니다.
2. 주소창에 **`intra.widdyax.com/m`** 를 입력해 접속합니다.
3. 화면 하단(또는 상단)의 **공유 버튼**을 누릅니다.
   - 📤 **네모 상자에 위쪽 화살표** 모양 아이콘입니다.
   - 하단 툴바가 안 보이면 화면을 살짝 **위로 스와이프**하면 나타납니다.
4. 나타난 메뉴를 **아래로 스크롤**하여 **"홈 화면에 추가"** 를 누릅니다.
5. 오른쪽 위 **"추가"** 를 누릅니다.
6. 홈 화면에 **워크핏 아이콘**(파란 배경 + 흰색 로고)이 생깁니다. ✅

---

## 2단계. 로그인

1. 홈 화면의 **워크핏 아이콘**을 눌러 앱을 실행합니다.
   - 주소창 없이 **전체화면**으로 뜨면 정상입니다.
2. **사번(또는 사내 이메일)** 과 **비밀번호**를 입력하고 **로그인**을 누릅니다.
   - 초기 비밀번호는 관리자에게 문의하세요.

---

## 3단계. 알림(푸시) 켜기 — ⭐ 가장 중요

1. 로그인 후, 화면 **우측 상단의 🔔(종) 버튼**을 누릅니다.
2. **"'워크핏'에서 알림을 보내려고 합니다"** 팝업이 뜨면 **"허용"** 을 누릅니다.
3. 화면 상단에 **"✅ 알림이 켜졌습니다"** 가 뜨면 완료입니다.

이제 다른 사람이 메시지를 보내면, **잠금화면·알림센터에 푸시 알림**이 도착합니다. 🔔

---

## 💬 사용법 요약

- **채팅방 목록**: 대화방을 눌러 입장, 안 읽은 메시지는 빨간 숫자 배지로 표시
- **메시지 보내기**: 하단 입력창에 입력 후 전송(↑) 버튼
- **답글(인용)**: (지원 시) 상대 메시지에 답장하면 원문이 인용되어 표시
- **사진/파일**: 대화방에서 첨부 확인·다운로드

## ❓ 문제 해결 (FAQ)

**Q. "홈 화면에 추가"가 안 보여요.**
→ 크롬 등 다른 브라우저입니다. **Safari**로 다시 접속하세요.

**Q. 🔔를 눌러도 권한 팝업이 안 떠요.**
→ 이미 차단했을 수 있습니다. **설정 → 앱 → Safari → (해당 사이트)** 또는 **설정 → 알림 → 워크핏** 에서 알림을 **허용**으로 바꾼 뒤, 앱을 껐다 켜고 다시 🔔.

**Q. 알림이 안 와요.**
→ 다음을 확인하세요.
1. **설정 → 알림 → 워크핏** 이 "허용"인지
2. **집중 모드/방해 금지**가 켜져 있지 않은지
3. **꼭 "홈 화면에 추가"한 앱**에서 알림을 켰는지 (Safari 탭에서 켠 건 무효)

**Q. iOS가 16.4보다 낮아요.**
→ 웹 푸시가 지원되지 않습니다. **설정 → 일반 → 소프트웨어 업데이트**로 iOS를 올리거나, 사내 배포 앱(있는 경우)을 사용하세요.

**Q. 로그인이 안 돼요.**
→ 사번/비밀번호를 확인하고, 계정이 "사용" 상태인지 관리자에게 문의하세요. (퇴사·잠금 계정은 로그인 불가)
