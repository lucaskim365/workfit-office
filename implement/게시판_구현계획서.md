# 게시판 기본 UI 화면 생성 구현 계획서 (화면 전환 방식)

## 1. 개요
* **목적**: 그룹웨어 내 전사 소통 및 공식 안내를 위한 게시판 모듈의 뼈대 화면을 신규 구축하고 사용자 인터페이스(UI) 및 화면 제어 흐름을 확립합니다.
* **디자인 결정**: 사용자의 읽기 몰입도를 높이고 향후 특정 게시물 공유/링크 주소 연동을 원활히 하기 위해, 기존 **팝업(모달) 방식에서 우측 영역 전체 화면 전환(Inner View State) 방식**으로 전환 구현합니다.

---

## 2. 화면 및 컴포넌트 구조

### 2.1 파일 레이아웃
```text
src/
 ├─ modules/
 │   └─ gw/
 │       └─ board/
 │           └─ BoardScreen.tsx  <-- 신규 생성
 └─ app/
     └─ App.tsx                  <-- 라우트 바인딩 및 Lazy 로딩 등록
```

### 2.2 메인 레이아웃 및 영역 설계
* **좌측: 게시판 네비게이션 사이드바 (고정)**
  * 게시판 종류를 전환해도 좌측 사이드바는 항시 유지되어 타 게시판으로의 빠른 이동을 보장합니다.
  * 지원 게시판: 공지사항(📢), 경조사(💐), 사내규정(📑), 자료실(📁)
* **우측: 화면 전환 뷰어 (상태 기반 전환)**
  * 활성화된 `viewMode` 상태(`'list' | 'detail' | 'write'`)에 따라 아래의 세 가지 내부 뷰 화면을 동적으로 갈아끼웁니다.
  1. **목록 뷰 (`list`)**: 게시글 리스트 테이블, 검색 바, 새 글 쓰기 버튼이 노출되는 목록 첫 화면.
  2. **상세 조회 뷰 (`detail`)**: 선택된 게시글의 제목, 정보 바, 본문, 첨부파일, 댓글 목록 등이 전체 너비로 시원하게 배치되는 화면. (상단에 '목록으로' 이동 버튼 제공)
  3. **게시글 작성 뷰 (`write`)**: 게시판 선택, 제목, 본문 작성 에디터 영역, 옵션 체크박스(중요 공지, 댓글 허용)가 전체 너비로 표시되는 작성 화면. (상단에 '취소' 및 '저장' 버튼 제공)

---

## 3. 화면 상세 제어 흐름 (Inner View State)

1. **상세 조회 화면 전환 (게시글 클릭 시)**
   * 게시물 행을 클릭하면 `viewMode`가 `'detail'`로 변경되고 우측 영역 전체가 상세 내용 뷰로 바뀝니다.
   * 전체 가로 공간을 넓게 사용하여 장문의 서식 및 첨부파일을 쾌적하게 렌더링합니다.
   * 상단의 `← 목록으로` 버튼 클릭 시 기존 검색어 및 탭 컨텍스트를 유지한 채 목록 뷰로 복귀합니다.
2. **게시글 작성 화면 전환 (새 글 쓰기 클릭 시)**
   * 목록 우측 상단의 `✍️ 새 글 쓰기` 버튼 클릭 시 `viewMode`가 `'write'`로 바뀌며 우측 영역 전체가 폼 양식으로 전환됩니다.
   * 취소 및 등록 액션 수행 시 다시 목록 뷰로 돌아갑니다.

---

## 4. 향후 백엔드(Firebase) 연동 개발 계획

향후 기능 고도화 시 아래와 같은 Firebase Firestore 연동 설계로 즉시 전환할 수 있도록 컴포넌트 아키텍처를 설계해 두었습니다.

* **컬렉션 구조**:
  * `boards` (게시판 마스터 정보)
  * `posts` (게시물 데이터, `boardId` 및 `isPinned` 인덱스 생성 필요)
  * `comments` (게시물 하위 서브 컬렉션 또는 독립 컬렉션 연동)
* **연동 로직**:
  * React Query 또는 Firebase SDK 실시간 리스너(`onSnapshot`)를 활용해 `useBoards`, `usePosts` 등의 커스텀 훅을 생성하여 현재 Mock 데이터가 바인딩된 부분을 교체 적용.
