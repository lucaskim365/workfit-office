# Rule: Daily Work Report Generation ([업무보고])

사용자가 프롬프트에 `[업무보고]` 단어를 포함하거나 요청하는 경우, 반드시 아래의 공식 표 양식에 맞추어 마크다운 형태로 일일 업무 보고서를 작성해야 합니다.

## 작성 양식 및 요건

1. **상단 타이틀 및 기본 정보**:
   * 제목: `# 일 일 업 무 보 고`
   * 기본 정보 표:
     | 일자 | 부서 | 작성자 |
     (일자: 현재 날짜 YYYY-MM-DD, 부서: 데이터플랫폼 개발팀, 작성자: 홍채원 — 사용자 정보 우선)

2. **업무 수행 내역 테이블 구조 (4단 고정 컬럼)**:
   * **순번**: 1, 2, 3, ...
   * **업무 내용**: 핵심 작업 명칭 및 대상 기능 (볼드체 강조)
   * **배경/원인**: 작업 배경, 필요성, 버그 원인 등을 글머리 기호(`-`)와 `<br>` 개행을 사용해 개조식으로 기술
   * **조치/해결책**: 구체적인 구현 내용, 해결책, 검증 결과 등을 글머리 기호(`-`)와 `<br>` 개행을 사용해 개조식으로 기술

## 표준 출력 서식 예시

# 일 일 업 무 보 고

| 일자 | 2026-09-15 | 부서 | 데이터플랫폼 개발팀 | 작성자 | 홍채원 |
| :---: | :---: | :---: | :---: | :---: | :---: |
